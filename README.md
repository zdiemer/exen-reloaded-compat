# exen-reloaded-compat

Per-game compatibility tracking for [exen-reloaded](https://github.com/zdiemer/exen-reloaded), the
portable reimplementation of In-Fusio's ExEn mobile games platform.

- [`COMPATIBILITY.md`](COMPATIBILITY.md): the current scoreboard, tiers and causes.
- One issue per game, labelled `status: <tier>` and `group: <cause>`, with a representative frame,
  run metrics and how to reproduce.
- `shots/` and `clips/`: what each game looked like during its run.

Everything here is generated by `tools/harness/compat.py` in the exen-reloaded repository:

```sh
python tools/harness/compat.py run "$EXEN_GAMES_DIR" --out <this repo>
python tools/harness/compat.py publish --out <this repo> --repo zdiemer/exen-reloaded-compat
```

No games are included. The screenshots and clips are captures of each game running, for
preservation and compatibility tracking.
